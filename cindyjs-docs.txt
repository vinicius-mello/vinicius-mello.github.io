Summary of CindyScript / CindyJS
Source: official CindyJS documentation (cindyjs.org/ref)

This file summarizes CindyScript syntax and the most common usage patterns for quick reference.
The examples below are practical summaries, not the full documentation.

==================================================
1. Control Structures
==================================================
if(condition, expression)
if(condition, exprTrue, exprFalse)
while(condition, expression)
repeat(number, expression)
repeat(number, variable, expression)
forall(list, expression)
forall(list, variable, expression)
regional(a, b, c)
createvar(x)
removevar(x)

Examples:
if(x < 0, println("negative"));
if(x > 0, 1, -1);
repeat(5, i, println(i));
forall(1..5, k, draw((k, k)));

==================================================
2. Drawing and Visualization
==================================================
draw(obj)
draw(pointA, pointB)
drawall(list)
connect(pointList)
drawpoly(pointList)
fillpoly(pointList)
drawcircle(center, radius)
fillcircle(center, radius)
drawarc(p1, p2, p3)
fillarc(p1, p2, p3)
drawtext(position, text)

Common modifiers:
color->(r,g,b)
alpha->0.8
size->4
pointsize->6
linesize->2
pointcolor->(1,0,0)
linecolor->(0,0,1)
start->1
stop->10
step->2
dashtype->2
dashing->4
dashpattern->[4,2]

Examples:
draw((1,2), color->(1,0.4,0));
drawcircle((0,0), 2, color->(0,0.7,1));
fillcircle((0,0), 1, color->(1,0,0), alpha->0.4);
drawtext((2,3), "Hi");

==================================================
10. Syntax Notes
==================================================
Variable assignment:
x = 10;

Function definition:
f(x) := x^2 + 1;

Sequence of commands:
a = 1;
b = 2;
println(a + b);

Modifiers use arrows:
draw(A, color->(1,0,0), size->5);

Lists:
[1,2,3]

Vectors can also be written with parentheses:
(1,2)

Integer range:
1..10

==================================================
11. Useful Mini Examples
==================================================
Point spiral:
repeat(200, i,
  p = (cos(i*12°), sin(i*12°)) * i / 30;
  draw(p, color->hue(i/30), size->3);
);

Filter even numbers:
select(1..20, # % 2 == 0);

Map squares:
apply(1..10, #^2);

Simple debug:
println("A=" + text(A.xy));

Time-based animation:
t = seconds();
draw((cos(t), sin(t)));
