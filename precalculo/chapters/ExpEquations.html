Resumo do capítulo

O capítulo reúne as principais técnicas para resolver equações e inequações exponenciais: igualar bases, aplicar logaritmo a ambos os lados e, quando necessário, usar substituição para reduzir a equação a uma forma polinomial conhecida.

Nos Exercícios 1 - 33, resolva a equação analiticamente.

  1. $2^{4x} = 8$
    resposta
    $x = \frac{3}{4}$
  2. $3^{(x - 1)} = 27$
    resposta
    $x = 4$
  3. $5^{2x-1} = 125$

    resposta
    $x=2$

  1. $4^{2x} = \frac{1}{2}$
    resposta
    $x = -\frac{1}{4}$
  2. $8^{x} = \frac{1}{128}$
    resposta
    $x = -\frac{7}{3}$
  3. $2^{(x^{3} - x)} = 1$

    resposta
    $x = -1, \, 0, \, 1$

  1. $3^{7x} = 81^{4-2x}$
    resposta
    $x = \frac{16}{15}$
  2. $9 \cdot 3^{7x} = \left(\frac{1}{9}\right)^{2x}$
    resposta
    $x=-\frac{2}{11}$
  3. $3^{2x} = 5$

    resposta
    $x = \frac{\ln(5)}{2\ln(3)}$

  1. $5^{-x} = 2$
    resposta
    $x = -\frac{\ln(2)}{\ln(5)}$
  2. $5^{x} = -2$
    resposta
    Sem solução.
  3. $3^{(x - 1)} = 29$

    resposta
    $x = \frac{\ln(29) + \ln(3)}{\ln(3)}$

  1. $(1.005)^{12x} = 3$
    resposta
    $x = \frac{\ln(3)}{12\ln(1.005)}$
  2. $e^{-5730k} = \frac{1}{2}$
    resposta
    $k = \frac{\ln\left(\frac{1}{2}\right)}{-5730} = \frac{1}{5730} \ln(2)$
  3. $2000e^{0.1t} = 4000$

    resposta
    $t=\frac{\ln(2)}{0.1} = 10\ln(2)$

  1. $500\left(1-e^{2x}\right) = 250$
    resposta
    $x=\frac{1}{2}\ln\left(\frac{1}{2}\right) = -\frac{1}{2}\ln(2)$
  2. $70 + 90e^{-0.1t} = 75$
    resposta
    $t = \frac{\ln\left(\frac{1}{18}\right)}{-0.1} =10 \ln(18)$

  3. $30-6e^{-0.1x}=20$

    resposta
    $x=-10\ln\left(\frac{5}{3}\right) = 10\ln\left(\frac{3}{5}\right)$

  1. $\dfrac{100e^{x}}{e^{x}+2}=50$
    resposta
    $x=\ln(2)$

  2. $\dfrac{5000}{1+2e^{-3t}}=2500$
    resposta
    $t=\frac{1}{3}\ln(2)$
  3. $\dfrac{150}{1 + 29e^{-0.8t}} = 75$

    resposta
    $t = \frac{\ln\left(\frac{1}{29}\right)}{-0.8} = \frac{5}{4}\ln(29)$

  1. $25\left(\frac{4}{5}\right)^{x} = 10$

    resposta
    $x = \frac{\ln\left(\frac{2}{5}\right)}{\ln\left(\frac{4}{5}\right)} = \frac{\ln(2)-\ln(5)}{\ln(4) - \ln(5)}$

  2. $e^{2x} = 2e^{x}$
    resposta
    $x = \ln(2)$

  3. $7e^{2x} = 28e^{-6x}$

    resposta
    $x = -\frac{1}{8} \ln\left(\frac{1}{4} \right) = \frac{1}{4}\ln(2)$

  1. $3^{(x - 1)} = 2^{x}$
    resposta
    $x = \frac{\ln(3)}{\ln(3) - \ln(2)}$

  2. $3^{(x - 1)} = \left(\frac{1}{2}\right)^{(x + 5)}$
    resposta
    $x = \frac{\ln(3) + 5\ln\left(\frac{1}{2}\right)}{\ln(3) - \ln\left(\frac{1}{2}\right)} = \frac{\ln(3)-5\ln(2)}{\ln(3)+\ln(2)}$
  3. $7^{3+7x} = 3^{4-2x}$

    resposta
    $x = \frac{4 \ln(3) - 3 \ln(7)}{7 \ln(7) + 2 \ln(3)}$

  1. $e^{2x} - 3e^{x}-10=0$
    resposta

  2. $e^{2x} = e^{x}+6$
    resposta
    $x=\ln(3)$
  3. $4^{x} + 2^{x} = 12$

    resposta
    $x=\frac{\ln(3)}{\ln(2)}$

  1. $e^{x}-3e^{-x}=2$
    resposta
    $x=\ln(3)$
  2. $e^{x}+15e^{-x}=8$
    resposta
    $x=\ln(3)$, $\ln(5)$
  3. $3^{x}+25\cdot3^{-x}=10$

    resposta
    $x=\frac{\ln(5)}{\ln(3)}$

Nos Exercícios 34 - 39, resolva a inequação analiticamente.

  1. $e^{x} > 53$
    resposta
    $(\ln(53), \infty)$
  2. $1000\left(1.005\right)^{12t} \geq 3000$

    resposta
    $\left[\frac{\ln(3)}{12\ln(1.005)}, \infty\right)$

  1. $2^{(x^{3} - x)} < 1$
    resposta
    $(-\infty, -1) \cup (0, 1)$
  2. $25\left(\frac{4}{5}\right)^{x} \geq 10$

    resposta
    $\left(-\infty, \frac{\ln\left(\frac{2}{5}\right)}{\ln\left(\frac{4}{5}\right)} \right] = \left(-\infty, \frac{\ln(2)-\ln(5)}{\ln(4)-\ln(5)} \right]$

  1. $\dfrac{150}{1 + 29e^{-0.8t}} \leq 130$

    resposta
    $\left(-\infty, \frac{\ln\left(\frac{2}{377}\right)}{-0.8} \right] = \left(-\infty, \frac{5}{4}\ln\left(\frac{377}{2}\right) \right]$
  2. $\vphantom{\dfrac{150}{1 + 29e^{-0.8t}}} 70 + 90e^{-0.1t} \leq 75$

    resposta
    $\left[\frac{\ln\left(\frac{1}{18}\right)}{-0.1}, \infty\right) = [10\ln(18), \infty)$

  1. Como $f(x) = \ln(x)$ é uma função estritamente crescente, se $0 < a < b$ então $\ln(a) < \ln(b)$. Use este fato para resolver a desigualdade $e^{(3x - 1)} > 6$ sem um diagrama de sinais. Utilize esta técnica para resolver as inequações nos Exercícios 34 - 39. (NOTA: Isole a função exponencial primeiro!)

    resposta
    $x > \frac{1}{3}(\ln(6) + 1)$

  2. Calcule a inversa de $f(x) = \dfrac{e^{x} - e^{-x}}{2}$. Indique o domínio e a imagem de $f$ e $f^{-1}$.

    resposta
    $f^{-1} = \ln\left(x + \sqrt{x^{2} + 1}\right)$. Tanto $f$ quanto $f^{-1}$ têm domínio $(-\infty, \infty)$ e imagem $(-\infty, \infty)$.

  3. Vamos mostrar rigorosamente que $f^{-1}(x) = \ln\left(\dfrac{x}{5-x}\right)$ é de fato a inversa de $f(x) = \dfrac{5e^{x}}{e^{x}+1}$.

    1. Mostre que $\left(f^{-1} \circ f\right)(x) = x$ para todo $x$ no domínio de $f$ e que $\left(f \circ f^{-1 }\right)(x) = x$ para todo $x$ no domínio de $f^{-1}$.

    2. Encontre a imagem de $f$ encontrando o domínio de $f^{-1}$.

    3. Seja $g(x) = \dfrac{5x}{x+1}$ e $h(x) = e^{x}$. Mostre que $f = g \circ h$ e que $(g \circ h)^{-1} = h^{-1} \circ g^{-1}$. (Sabemos que isso é verdade em geral pelo Exercício 30 na Capítulo 18, mas é bom ver um exemplo específico da propriedade.)

  4. Com a ajuda de seus colegas, resolva a inequação $e^{x} > x^{n}$ para uma variedade de números naturais $n$. O que você poderia conjecturar sobre a “velocidade” na qual $f(x) = e^{x}$ cresce em comparação com qualquer polinômio?
