Funções Exponencial e Logarítmica

21 Propriedades do Logaritmo

Resumo do capítulo

As propriedades de produto, quociente e potência do logaritmo, junto com a fórmula de mudança de base, permitem reescrever e simplificar expressões logarítmicas. Este capítulo pratica essas manipulações, essenciais para resolver as equações dos capítulos seguintes.

Nos Exercícios 1 - 15, expanda o logaritmo dado e simplifique. Suponha, quando necessário, que todas as quantidades representam números reais positivos.

  1. $\ln(x^{3}y^{2})$
    resposta
    $3\ln(x) + 2\ln(y)$
  2. $\log_{2}\left(\dfrac{128}{x^{2} + 4}\right)$
    resposta
    $7 - \log_{2}(x^{2} + 4)$

  3. $\log_{5}\left(\dfrac{z}{25}\right)^{3}$

    resposta
    $3\log_{5}(z) - 6$

  1. $\log(1.23 \times 10^{37})$
    resposta
    $\log(1.23) + 37$

  2. $\ln\left(\dfrac{\sqrt{z}}{xy}\right)$
    resposta
    $\frac{1}{2}\ln(z) - \ln(x) - \ln(y)$
  3. $\log_{5} \left(x^2 - 25 \right)$

    resposta
    $\log_{5}(x-5) + \log_{5}(x+5)$

  1. $\log_{\sqrt{2}} \left(4x^3\right)$
    resposta
    $3\log_{\sqrt{2}}(x) + 4$
  2. $\log_{\frac{1}{3}}(9x(y^{3} - 8))$
    resposta
    $-2 + \log_{\frac{1}{3}}(x) + \log_{\frac{1}{3}}(y - 2) + \log_{\frac{1}{3}}(y^{2} + 2y + 4)$

  3. $\log\left(1000x^3y^5\right)$

    resposta
    $3 + 3\log(x) + 5 \log(y)$

  1. $\log_{3} \left(\dfrac{x^2}{81y^4}\right)$
    resposta
    $2\log_{3}(x) - 4 - 4\log_{3}(y)$

  2. $\ln\left(\sqrt[4]{\dfrac{xy}{ez}}\right)$
    resposta
    $\frac{1}{4} \ln(x) + \frac{1}{4} \ln(y) - \frac{1}{4} - \frac{1}{4} \ln(z)$
  3. $\log_{6} \left(\dfrac{216}{x^3y}\right)^4$

    resposta
    $12-12\log_{6}(x) - 4\log_{6}(y)$

  1. $\log\left(\dfrac{100x\sqrt{y}}{\sqrt[3]{10}}\right)$
    resposta
    $\frac{5}{3}+\log(x)+\frac{1}{2}\log(y)$
  2. $\log_{\frac{1}{2}}\left(\dfrac{4\sqrt[3]{x^2}}{y\sqrt{z}}\right)$
    resposta
    $-2+\frac{2}{3}\log_{\frac{1}{2}}(x)-\log_{\frac{1}{2}}(y)-\frac{1}{2}\log_{\frac{1}{2}}(z)$

  3. $\ln \left(\dfrac{\sqrt[3]{x}}{10 \sqrt{yz}}\right)$

    resposta
    $\frac{1}{3} \ln(x) - \ln(10) - \frac{1}{2}\ln(y)-\frac{1}{2}\ln(z)$

Nos Exercícios 16 - 29, use as propriedades dos logaritmos para escrever a expressão como um único logaritmo.

  1. $4\ln(x) + 2\ln(y)$

  2. $\log_{2}(x) + \log_{2}(y) - \log_{2}(z)$

    resposta
    $\log_{2}\left(\frac{xy}{z}\right)$

  1. $\log_{3}(x) - 2 \log_{3}(y)$

  2. $\frac{1}{2}\log_{3}(x) - 2\log_{3}(y) - \log_{3}(z)$

    resposta
    $\log_{3}\left(\frac{\sqrt{x}}{y^{2}z}\right)$

  1. $2 \ln(x) -3 \ln(y) - 4\ln(z)$
    resposta
    $\ln\left( \frac{x^2}{y^3z^4} \right)$
  2. $\log(x) - \frac{1}{3} \log(z) + \frac{1}{2} \log(y)$

    resposta
    $\log\left(\frac{x \sqrt{y}}{\sqrt[3]{z}} \right)$

  1. $-\frac{1}{3} \ln(x) - \frac{1}{3}\ln(y) + \frac{1}{3} \ln(z)$
    resposta
    $\ln\left(\sqrt[3]{\frac{z}{xy}} \right)$

  2. $\log_{5}(x) - 3$

    resposta
    $\log_{5}\left(\frac{x}{125}\right)$

  1. $3 - \log(x)$
    resposta
    $\log\left(\frac{1000}{x}\right)$
  2. $\log_{7}(x) + \log_{7}(x - 3) - 2$

    resposta
    $\log_{7}\left(\frac{x(x - 3)}{49}\right)$

  1. $\ln(x) + \frac{1}{2}$
    resposta
    $\ln \left(x \sqrt{e} \right)$
  2. $\log_{2}(x) + \log_{4}(x)$

    resposta
    $\log_{2}\left(x^{3/2}\right)$

  1. $\log_{2}(x) + \log_{4}(x-1)$
    resposta

  2. $\log_{2}(x) + \log_{\frac{1}{2}}(x - 1)$

    resposta
    $\vphantom{\frac{\log(x + 2)}{\log(3)}}\log_{2}\left(\frac{x}{x - 1}\right)$

Nos Exercícios 30 - 33, use a fórmula de mudança de base apropriada para converter a expressão dada em uma expressão com a base indicada.

  1. $7^{x - 1}$ para base $e$
    resposta
    $\vphantom{\frac{\log(x + 2)}{\log(3)}}7^{x - 1} = e^{(x - 1)\ln(7)}$
  2. $\log_{3}(x + 2)$ para base 10

    resposta
    $\log_{3}(x + 2) = \frac{\log(x + 2)}{\log(3)}$

  1. $\left(\dfrac{2}{3}\right)^{x}$ para base $e$
    resposta
    $\left(\frac{2}{3}\right)^{x} = e^{x\ln(\frac{2}{3})}$
  2. $\log(x^{2} + 1)$ para base $e$

    resposta
    $\log(x^{2} + 1) = \frac{\ln(x^{2} + 1)}{\ln(10)}$

  4. A equação de Henderson-Hasselbalch: Suponha que $HA$ represente um ácido fraco. Então temos uma reação química reversível \[HA \rightleftharpoons H^{+} + A^{-}.\] A constante de dissociação ácida, $K_{a}$, é dada por \[K_{a} = \frac{[H^{+}][A^{-}]}{[HA]} = [H^{+}]\frac{[A^{-}]} {[HA]},\] onde os colchetes denotam as concentrações exatamente como fizemos no Exercício 77 na Capítulo 20. O símbolo p$K_{a}$ é definido de forma semelhante ao pH em que p$K_{a} = -\log(K_{a})$. Usando a definição de pH do Exercício 77 e as propriedades dos logaritmos, derive a Equação de Henderson-Hasselbalch que afirma \[\mbox{pH} = \mbox{p}K_{a} + \log\dfrac{[A^{-}]}{[HA]}\]
