13 Divisão de Polinômios

Resumo do capítulo

Assim como números inteiros, polinômios podem ser divididos uns pelos outros. Este capítulo pratica a divisão longa e a divisão sintética de polinômios, além do Teorema do Resto e do Teorema do Fator, que relacionam o resto dessa divisão às raízes do polinômio.

Nos exercícios 1 - 6, efetue a divisão polinomial. Escreva o polinômio dado na forma $p(x) = d(x)q(x) + r(x)$.

  1. $\left(4x^2+3x-1 \right) \div (x-3)$
    resposta
    $4x^2+3x-1 = (x-3)(4x+15) + 44$
  2. $\left(2x^3-x+1 \right) \div \left(x^{2} +x+1 \right)$

    resposta
    $2x^3-x+1 = \left(x^2+x+1\right)(2x-2)+(-x+3)$

  1. $\left(5x^{4} - 3x^{3} + 2x^{2} - 1 \right) \div \left(x^{2} + 4 \right)$
    resposta
    $5x^{4} - 3x^{3} + 2x^{2} - 1 = \left(x^{2} + 4 \right) \left(5x^{2} - 3x - 18 \right) + (12x + 71)$
  2. $\left(-x^{5} + 7x^{3} - x \right) \div \left(x^{3} - x^{2} + 1 \right)$

    resposta
    $-x^{5} + 7x^{3} - x = \left(x^{3} - x^{2} + 1 \right) \left(-x^{2} - x + 6 \right) + \left(7x^{2} - 6 \right)$

  1. $\left(9x^{3} + 5 \right) \div \left(2x - 3 \right)$
    resposta
    $9x^{3} + 5 =(2x - 3) \left(\frac{9}{2}x^{2} + \frac{27}{4}x + \frac{81}{8} \right) + \frac{283}{8}$
  2. $\left(4x^2 - x - 23 \right) \div \left(x^{2} - 1 \right)$

    resposta
    $4x^2 - x - 23 = \left(x^{2} - 1 \right)(4) + (-x - 19)$

Nos exercícios 7 - 20 use o dispositivo de Briot-Ruffini para efetuar a divisão de polinômios. Escreva o polinômio dado na forma $p(x) = d(x)q(x) + r(x)$.

  1. $\left(3x^2-2x+1 \right) \div \left(x-1\right)$
    resposta
    $\left(3x^2-2x+1 \right) = \left(x-1\right) (3x+1)+2$
  2. $\left(x^2-5 \right) \div \left(x-5\right)$

    resposta
    $\left(x^2-5 \right)= \left(x-5\right)(x+5) + 20$

  1. $\left(3-4x-2x^2 \right) \div \left(x+1\right)$
    resposta
    $\left(3-4x-2x^2 \right) = \left(x+1\right)(-2x-2)+5$
  2. $\left(4x^2-5x +3\right) \div \left(x+3\right)$

    resposta
    $\left(4x^2-5x +3\right) = \left(x+3\right)(4x-17)+54$

  1. $\left(x^3 + 8 \right) \div \left(x+2\right)$
    resposta
    $\left(x^3 + 8 \right) = \left(x+2\right) \left(x^2-2x+4\right) + 0$
  2. $\left(4x^3 +2x-3 \right) \div \left(x -3\right)$

    resposta
    $\left(4x^3 +2x-3 \right) = \left(x -3\right) \left(4x^2+12x+38\right) + 111$

  1. $\left(18x^2-15x-25\right) \div \left(x - \frac{5}{3} \right)$
    resposta
    $\left(18x^2-15x-25\right) = \left(x - \frac{5}{3} \right)(18x+15)+0$
  2. $\left(4x^2-1 \right) \div \left(x - \frac{1}{2} \right)$

    resposta
    $\left(4x^2-1 \right) = \left(x - \frac{1}{2} \right)(4x+2)+0$

  1. $\left(2x^3+x^2+2x+1 \right) \div \left(x + \frac{1}{2} \right)$
    resposta
    $\left(2x^3+x^2+2x+1 \right) = \left(x + \frac{1}{2} \right)\left(2x^2+2\right)+0$
  2. $\left(3x^3 - x + 4 \right) \div \left(x - \frac{2}{3} \right)$

    resposta
    $\left(3x^3 - x + 4 \right) = \left(x - \frac{2}{3} \right) \left(3x^2+2x+\frac{1}{3}\right) + \frac{38}{9}$

  1. $\left(2x^3 - 3x +1 \right) \div \left(x - \frac{1}{2} \right)$
    resposta
    $\left(2x^3 - 3x +1 \right) = \left(x - \frac{1}{2} \right) \left(2x^2+x-\frac{5}{2}\right)-\frac{1}{4}$
  2. $\left(4x^4-12x^3+13x^2 -12x+9\right) \div \left(x - \frac{3}{2} \right)$

    resposta
    $\left(4x^4-12x^3+13x^2 -12x+9\right) = \left(x - \frac{3}{2} \right) \left(4x^3-6x^2+4x-6 \right)+0$

  1. $\left(x^4-6x^2+9 \right) \div \left(x -\sqrt{3} \right)$
    resposta
    $\left(x^4-6x^2+9 \right) = \left(x -\sqrt{3} \right) \left(x^3+\sqrt{3} \,x^2-3x-3\sqrt{3}\right) + 0$
  2. $\left(x^6-6x^4+12x^2-8\right) \div \left(x +\sqrt{2} \right)$

    resposta
    $\left(x^6-6x^4+12x^2-8\right) = \left(x +\sqrt{2} \right) \left(x^5-\sqrt{2} \, x^4-4x^3+4\sqrt{2} \, x^2+4x-4\sqrt{2}\right) + 0$

Nos exercícios 21 - 30, determine $p(c)$ usando o Teorema do Resto para a função polinomial e para o valor de $c$ dados. Se $p(c) = 0$, fatore $p(x) = (x-c) q(x)$.

  1. $p(x) = 2x^2 - x + 1$, $c = 4$
    resposta
    $p(4) = 29$
  2. $p(x) = 4x^2-33x-180$, $c = 12$

    resposta
    $p(12) =0$, $p(x) = (x-12)(4x+15)$

  1. $p(x) = 2x^3 - x + 6$, $c=-3$
    resposta
    $p(-3)=-45$
  2. $p(x) = x^3+2x^2+3x+4$, $c =-1$

    resposta
    $p(-1)=2$

  1. $p(x) =3x^3-6x^2+4x-8$, $c=2$
    resposta
    $p(2) =0$, $p(x)= (x-2) \left(3x^2+4\right)$
  2. $p(x) = 8x^3+12x^2+6x+1$, $c =-\frac{1}{2}$

    resposta
    $p\left(-\frac{1}{2}\right) = 0$, $p(x) = \left(x+\frac{1}{2}\right)\left(8x^2+8x+2\right)$

  1. $p(x) = x^4 - 2x^2+4$, $c=\frac{3}{2}$
    resposta
    $p\left(\frac{3}{2}\right) = \frac{73}{16}$
  2. $p(x) = 6x^4-x^2+2$, $c =-\frac{2}{3}$

    resposta
    $p\left(-\frac{2}{3}\right) = \frac{74}{27}$

  1. $p(x) = x^4 +x^3-6x^2-7x-7$, $c=-\sqrt{7}$
    resposta
    $p(-\sqrt{7}) = 0$, $p(x) = (x+\sqrt{7})\left(x^3+(1-\sqrt{7}) x^2+(1-\sqrt{7})x-\sqrt{7} \right)$
  2. $p(x) = x^2-4x+1$, $c =2-\sqrt{3}$

    resposta
    $p(2-\sqrt{3}) =0$, $p(x) = (x-(2-\sqrt{3}))(x-(2+\sqrt{3})) $

Nos exercícios 31 - 40, são dados um polinômio e um de seus zeros. Use os métodos conhecidos e tentativa e erro para encontrar os demais zeros e fatorar o polinômio.

  1. $x^{3} - 6x^{2} + 11x - 6, \;\; c = 1$
    resposta
    $x^{3} - 6x^{2} + 11x - 6 = (x - 1)(x - 2)(x - 3)$
  2. $x^{3} - 24x^{2} + 192x - 512, \;\; c = 8$

    resposta
    $x^{3} - 24x^{2} + 192x - 512 = (x - 8)^{3}$

  1. $3x^{3} + 4x^{2} - x - 2, \;\; c = \frac{2}{3}$
    resposta
    $3x^{3} + 4x^{2} - x - 2 = 3\left(x - \frac{2}{3}\right)(x + 1)^{2}$

  2. $2x^3-3x^2-11x+6, \;\; c=\frac{1}{2}$

    resposta
    $2x^3-3x^2-11x+6 = 2\left(x-\frac{1}{2}\right)(x+2)(x-3)$

  1. $x^3+2x^2-3x-6, \;\; c = -2$
    resposta
    $x^3+2x^2-3x-6 = (x+2)(x+\sqrt{3})(x-\sqrt{3})$
  2. $2x^3-x^2-10x+5, \;\; c=\frac{1}{2}$

    resposta
    $2x^3-x^2-10x+5=2\left(x-\frac{1}{2}\right)(x+\sqrt{5})(x-\sqrt{5})$

  1. $4x^{4} - 28x^{3} + 61x^{2} - 42x + 9$, $c = \frac{1}{2}$ é um zero de multiplicidade 2

    resposta
    $4x^{4} - 28x^{3} + 61x^{2} - 42x + 9 = 4\left(x - \frac{1}{2} \right)^{2}(x - 3)^{2}$

  2. $x^5+2x^4-12x^3-38x^2-37x-12$, $c=-1$ é um zero de multiplicidade 3

    resposta
    $x^5+2x^4-12x^3-38x^2-37x-12 = (x+1)^3(x+3)(x-4)$

  3. $125x^{5} - 275x^{4} - 2265x^{3} - 3213x^{2} - 1728x - 324$, $c = -\frac{3}{5}$ é um zero de multiplicidade 3

    resposta
    $125x^{5} - 275x^{4} - 2265x^{3} - 3213x^{2} - 1728x - 324$ = $125\left(x + \frac{3}{5} \right)^{3}(x + 2)(x - 6)$

  4. $x^{2} - 2x - 2, \;\; c = 1 - \sqrt{3}$

    resposta
    $x^{2} - 2x - 2 = (x - (1 - \sqrt{3}))(x - (1 + \sqrt{3}))$

Nos exercícios 41 - 45, crie um polinômio $p$ que tenha as características desejadas. Pode deixar o polinômio na forma fatorada.

    • Os zeros de $p$ são $c = \pm 2$ e $c = \pm 1$
    • O termo principal de $p(x)$ é $117x^4$.

    resposta
    $p(x) = 117(x+2)(x-2)(x+1)(x-1)$

    • Os zeros de $p$ são $c=1$ e $c = 3$
    • $c=3$ é um zero de multiplicidade 2.
    • O termo principal de $p(x)$ é $-5x^3$

    resposta
    $p(x)= -5(x-1)(x-3)^2$

    • As soluções de $p(x) = 0$ são $x = \pm 3$ e $x=6$
    • O termo principal de $p(x)$ é $7x^4$
    • O ponto $(-3,0)$ é um mínimo local do gráfico de $y=p(x)$.

    resposta
    $p(x) = 7(x+3)^2(x-3)(x-6)$

    • As soluções de $p(x) =0$ são $x = \pm 3$, $x=-2$ e $x=4$.
    • O termo principal de $p(x)$ é $-x^5$.
    • O ponto $(-2, 0)$ é um máximo local do gráfico de $y=p(x)$.

    resposta
    $p(x) = -(x + 2)^{2}(x - 3)(x + 3)(x - 4)$

    • $p$ tem grau 4.
    • quando $x \rightarrow \infty$, $p(x) \rightarrow -\infty$
    • $p$ tem exatamente três interseções com o eixo $x$: $(-6,0)$, $(1,0)$ e $(117,0)$
    • O gráfico de $y=p(x)$ cruza o eixo $x$ em $(1,0)$.

    resposta
    $p(x) = a(x+6)^2(x-1)(x-117)$ onde $a$ pode ser um número negativo qualquer

    resposta
    $p(x) = 5x^{2} - 6x - 4$
